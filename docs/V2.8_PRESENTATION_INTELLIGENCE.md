# V2.8 Sprint 1 — Presentation Intelligence Layer

## Objective

Add visual diversity to FaceEngine without modifying CreatureState or any behavioral engine. Each emotion gains 2-3 presentation variants; transitions become smooth; variant selection is context-driven by mood, engagement, and activity.

## Architecture Rule

> FaceEngine may derive temporary presentation state (profiles, transitions, animation timing) from CreatureState, but must never modify CreatureState or influence behavioral decisions. All presentation state is ephemeral and private to FaceEngine.

## Data Structures

### PresentationProfile (PROGMEM)

```cpp
struct PresentationProfile {
  uint8_t variant_id;          // 0..2 within emotion
  uint8_t eye_shape;           // ARCHED/ROUND/FLAT/SQUINT/WIDE
  uint8_t brow_style;          // NORMAL/RAISED/FURROWED/ONE/WORRIED
  uint8_t pupil_style;         // NORMAL/DILATED/CONSTRICTED/HALF/NONE
  uint8_t color_override;      // 0 = emotion default, else color table index
  uint8_t anim_profile_id;     // index into AnimationProfile table
  int8_t  mood_affinity[3];    // -3..+3 per RELAXED/PLAYFUL/ANXIOUS
  uint8_t engagement_min;      // 0-100
  uint8_t engagement_max;      // 0-100
  uint8_t context_bucket;      // CALM=0 / ACTIVE=1 / FOCUSED=2 / SOCIAL=3 / ANY=255
  uint8_t hold_ms;             // minimum display time before re-selection
};
// 13 bytes per variant, stored in 2D array indexed by emotion
```

### PresentationState (RAM, private to FaceEngine)

```cpp
struct PresentationState {
  uint8_t  current_profile;     // global index 0..24
  uint8_t  pending_profile;     // for transitions
  uint8_t  transition_progress; // 0-255
  uint16_t hold_remaining_ms;   // time until variant can change
  uint32_t selection_seed;      // deterministic PRNG state
  EmotionType last_emotion;     // for detecting emotion changes
  MoodType    last_mood;        // for detecting context shifts
  uint8_t     last_engagement;  // for detecting threshold crossings
};
// 11 bytes RAM
```

### AnimationProfile (PROGMEM)

```cpp
struct AnimationProfile {
  uint8_t blink_mod;       // 128 = 1.0x multiplier on mood baseline
  uint8_t gaze_range;      // max pupil offset in pixels
  uint8_t idle_speed_mod;  // 128 = 1.0x
  uint8_t bounce_mod;      // 128 = 1.0x
};
// 4 bytes per profile, ~8 profiles
```

## Selection Algorithm (Event-Driven)

Variant selection runs only when triggered:

1. **Emotion change** (`g_creature.emotion != last_emotion`)
2. **Hold expiry** (`hold_remaining_ms == 0`)
3. **Context shift** (mood changed, or engagement crossed a profile's min/max)

Selection scores each profile in the current emotion's pool using weights, then picks via deterministic PRNG (xorshift32). The PRNG advances only on selection — not every frame.

## Transition Management

When emotion changes:
- Snap eye shape, brow, pupil type immediately
- Interpolate position, scale, eyelid openness, color over ~250ms
- Hold new variant for `profile.hold_ms` before allowing re-selection
- Interruption: new emotion during transition restarts immediately
