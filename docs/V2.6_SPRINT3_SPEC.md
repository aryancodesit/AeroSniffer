# V2.6 Sprint 3 — Memory Domain Expansion

**Goal:** Add Security, Aviation, and Mood memory domains to MemoryEngine, expanding memory beyond touch-only without changing any existing certified subsystems.

**Foundation:** V2.6 Sprint 2 certified — Touch Memory Expansion stable on hardware.

---

## Current State (Before Sprint 3)

```
Memory Domains:            DOMAIN_TOUCH only
Memory Subtypes:           5 touch subtypes (TAP, DOUBLE, HOLD, LONG_HOLD, BURST)
MemoryEventCallback:        handles EVENT_TOUCH_SHORT only
MemoryRecord.data union:    1 member (touch)
MemoryRecord.source_id:     not present
MemorySummary:              tracks ms_since_last_touch
```

## Sprint 3 Objective

```
Memory Domains:            DOMAIN_TOUCH + DOMAIN_SECURITY + DOMAIN_AVIATION + DOMAIN_MOOD
Memory Subtypes:           5 touch + 3 security + 3 aviation + 4 mood = 15 total
```

## Design Constraints

### 1. Episodes > Telemetry

Memory records represent *experiences*, not telemetry samples.

| Domain | Raw Event | Forms Memory? | Condition |
|--------|-----------|---------------|-----------|
| Touch | Press/release | Yes | Every debounced touch |
| Security | Deauth packet | Conditional | Counted; memory forms at SUSPICIOUS (2-4) or THREAT (5+) per window. Single deauth = no memory |
| Security | Beacon frame | **No** | Not an episode |
| Aviation | Flight detected | Yes | First detection per aircraft |
| Aviation | Position update | **No** | Not a new episode |
| Mood | Tick | **No** | Only on transition or 30+min prolonged |

### 2. Observer > Controller

Memory reads state. It does not write state.

```
MemoryEngine reads:   EventBus events, g_creature.mood, g_creature.mood_strength
MemoryEngine writes:  its own ring buffer
MemoryEngine never:   modifies g_creature, MoodEngine, AttentionEngine, FaceEngine
```

### 3. No Changes to Certified Subsystems

| Subsystem | Sprint 2 Status | Sprint 3 Change |
|-----------|----------------|-----------------|
| MemoryTypes.h (structs/enums) | Frozen | **Add** subtypes + union members + source_id (additive only) |
| MemoryEngine.h | Frozen | **Add** new public/private methods + state (additive only) |
| MemoryEngine.cpp | Frozen | **Add** new domain logic (additive only) |
| AeroSniffer.ino | Frozen | **Modify** memory_event_callback (add cases) |
| MoodEngine | Frozen | **No change** |
| AttentionEngine | Frozen | **No change** |
| FaceEngine | Frozen | **No change** |
| EventBus | Frozen | **No change** |
| Mode tasks (Pet, Aviation, Portal) | Frozen | **No change** |
| Config.h | Frozen | **No change** |
| PersistenceService | Frozen | **No change** |

### 4. No Transition Dedup

MOOD_TRANSITION is never deduped. Each transition is a distinct emotional episode.

### 3. `AeroSniffer/Memory/MemoryEngine.cpp`

**`observe()` flow (updated):**

```
observe():
  → TOUCH: drain pending_[] buffer (unchanged from Sprint 2)
  → SECURITY: sec_ state updated by onSecurityEvent (consumed here)
  → AVIATION: check quiet sky condition
  → MOOD: compare g_creature.mood vs mood_.last_known_mood
          check prolonged mood (30+ min in same mood)
```

**`observe_security()`** — sets `source_id` from device hash (low 32 bits of MAC-derived identifier), calls `compute_salience()` then `try_dedup()`.

**`observe_aviation()`** — sets `source_id` = ICAO24, calls `compute_salience()` then `try_dedup()`.

**`observe_mood()`** — sets `source_id = 0`, calls `compute_salience()`. Does NOT call `try_dedup()` for MOOD_TRANSITION (window 0, skipped). Calls `try_dedup()` for MOOD_LONG_* subtypes with a 6-hour window as safety net (the per-mood period lock prevents duplicates under normal operation).

**`compute_salience()`** — no changes needed. Already generic (`uint8_t base` input, applies mood/mode/uptime multipliers).

**`try_dedup()`** — update domain-specific windows:

```cpp
uint32_t window_ms;
switch (domain) {
  case DOMAIN_TOUCH:    window_ms = 60000;  break;
  case DOMAIN_SECURITY: window_ms = 300000; break;  // 5 min
  case DOMAIN_AVIATION: window_ms = 180000; break;  // 3 min
  case DOMAIN_MOOD:     // MOOD_TRANSITION: window_ms=0 (caller skips try_dedup)
                        // MOOD_LONG_*: window_ms=21600000 (6h safety net)
                        window_ms = (subtype == MOOD_TRANSITION) ? 0 : 21600000;  break;
  default:              window_ms = 60000;  break;
}
if (window_ms == 0) return false;
// ... existing match logic
```

**`recall()`** — no change needed. `domain_strength[DOMAIN_COUNT]` automatically includes new domains via existing loop.

### 4. `AeroSniffer/AeroSniffer.ino`

```cpp
static void memory_event_callback(EventType event, void* data) {
  switch (event) {
    case EVENT_TOUCH_SHORT: {
      TouchEventData* td = (TouchEventData*)data;
      MemoryEngine.onTouchEvent(td ? td->duration_ms : 0);
      break;
    }
    case EVENT_ATTACK_DEAUTH:
    case EVENT_ATTACK_EVILTWIN:
    case EVENT_DEVICE_TRUSTED:
    case EVENT_DEVICE_FAMILIAR:
    case EVENT_DEVICE_UNKNOWN:
      MemoryEngine.onSecurityEvent(event);
      break;
    case EVENT_FLIGHT_DETECTED:
    case EVENT_FLIGHT_RARE:
      MemoryEngine.onFlightEvent(event, data);
      break;
    default:
      break;
  }
}
```

## Risks

| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|------------|
| Memory flood from security events | Medium | Medium | Deauth burst window (60s), dedup (5 min), 3 subtypes, no memory for single deauth |
| Memory flood from aviation events | Low | Medium | Event-driven, dedup (3 min), quiet sky cooldown (1h) |
| Memory flood from mood transitions | Low | Low | Transitions are rare (20-30 min typical); no dedup needed |
| Cross-domain salience imbalance | Low | Medium | Sprint 3 max = 50 (THREAT), normalized to touch range |
| Ring buffer dominated by one domain | Low | Medium | All domains within same salience range; LRU eviction |
| MoodEngine race condition | Low | High | MemoryEngine only reads g_creature.mood in tick() |
| Event callback reentrancy | Low | High | onSecurityEvent/onFlightEvent set flags; observe() consumes |
| Ring buffer eviction of touch by new domains | Medium | Low | Expected — more domains = more competition for 64 slots |
| Regression: touch memory | Low | High | Touch pipeline untouched |
