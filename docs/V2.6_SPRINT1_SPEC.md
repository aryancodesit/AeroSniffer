# V2.6 Sprint 1 — In-Memory Core (Touch-Only)

## Scope

Implement the MemoryEngine singleton with in-memory ring buffer only (no LittleFS persistence). Only DOMAIN_TOUCH events form memories. Only one behavior modulation path is active: engagement_drive decay rate influenced by recent touch history.

**Explicitly out of scope:**
- LittleFS read/write (Sprint 2)
- Security, Aviation, Mood, Attention domains (Sprint 3)
- Full behavior modulation table (Sprint 4)
- Familiarity and Significant memory categories (Sprint 3)

#ifndef MEMORY_TYPES_H
#define MEMORY_TYPES_H

#include <stdint.h>

enum MemoryCategory : uint8_t {
  MEM_CAT_NONE        = 0,
  MEM_CAT_EPISODIC    = 1,
  MEM_CAT_FAMILIARITY = 2,
  MEM_CAT_SIGNIFICANT = 3
};

enum MemoryDomain : uint8_t {
  DOMAIN_TOUCH     = 0,
  DOMAIN_SECURITY  = 1,
  DOMAIN_AVIATION  = 2,
  DOMAIN_MOOD      = 3,
  DOMAIN_ATTENTION = 4,
  DOMAIN_COUNT
};

enum TouchSubtype : uint8_t {
  TOUCH_TAP       = 0x01,
  TOUCH_DOUBLE    = 0x02,
  TOUCH_HOLD      = 0x03,
  TOUCH_BURST     = 0x04,
  TOUCH_LONG_HOLD = 0x05
};

struct MemoryRecord {
  uint32_t id;
  uint32_t formed_at_ms;
  uint8_t  category;       // MEM_CAT_EPISODIC only in Sprint 1
  uint8_t  domain;         // DOMAIN_TOUCH only in Sprint 1
  uint8_t  subtype;        // TouchSubtype
  uint8_t  salience;       // 0-100
  uint8_t  strength;       // 0-100
  uint8_t  recall_count;
  uint8_t  mood_at_formation;
  uint8_t  attention_at_form;
  uint8_t  mode_at_formation;
  uint8_t  padding;
  union {
    struct {
      uint16_t touch_duration_ms;
      uint8_t  tap_count_window;
      uint8_t  _pad[13];
    } touch;
    uint8_t raw[16];
  } data;
};

struct MemorySummary {
  uint8_t  domain_strength[DOMAIN_COUNT];
  uint8_t  episodic_count;
  uint8_t  familiarity_count;
  uint8_t  significant_present;

### `AeroSniffer/Memory/MemoryEngine.cpp`

Full implementation:
- `begin()` — zero-initialize ring buffer, set `boot_count_` from CreatureProfile
- `tick()` — call `observe()`, then `decay()` + `prune()` every 60s
- `observe()` — check touch formation conditions against g_creature, form records
- `decay()` — iterate records, apply half-life decay (Touch: 6h half-life)
- `prune()` — remove zero-strength records, compact array
- `recall()` — scan records, compute domain_strength, ms_since_last_touch
- `compute_salience()` — deterministic base × context multiplier
- `try_dedup()` — find matching (domain, subtype, <60s old) record, boost salience
- `evict_one()` — LRU eviction when ring buffer is full

## Touch Formation Conditions (Sprint 1 only)

| Event | Condition | Subtype | Base Salience |
|-------|-----------|---------|---------------|
| `EVENT_TOUCH_SHORT` | Single tap, debounced | TOUCH_TAP | 20 |
| Two `EVENT_TOUCH_SHORT` within 500ms | Inter-tap gap ≤ 500ms | TOUCH_DOUBLE | 35 |
| touch_press_duration > 2000ms | Held press | TOUCH_HOLD | 40 |
| >= 5 taps in 10s sliding window | Burst detected | TOUCH_BURST | 55 |
| touch_press_duration > 10000ms | Long hold | TOUCH_LONG_HOLD | 60 |

**Tap tracking:**
```cpp
// On each EVENT_TOUCH_SHORT:
tap_timestamps_[tap_index_ % 8] = millis();
tap_index_++;
touch_taps_session_++;

// Count taps in last 10s:
uint8_t count = 0;
for (uint8_t i = 0; i < min(tap_index_, 8); i++) {
  if (millis() - tap_timestamps_[i] <= 10000) count++;
}
if (count >= 5) form TOUCH_BURST;

// Double-tap detection:
if (tap_index_ >= 2) {
  uint32_t last_gap = tap_timestamps_[(tap_index_-1) % 8]
                    - tap_timestamps_[(tap_index_-2) % 8];
  if (last_gap <= 500 && last_gap > 50) form TOUCH_DOUBLE;
}

// After all checks, form TOUCH_TAP as fallback.
```

## recall() Implementation (Sprint 1)

```cpp
MemorySummary MemoryEngineClass::recall() {
  MemorySummary summary = {};
  uint32_t now = millis();
  uint32_t newest_touch_ms = 0;

  for (uint16_t i = 0; i < record_count_; i++) {
    auto& rec = records_[i];

    // Aggregate domain strength (strength-weighted)
    if (rec.strength > 0) {
      uint8_t w = (rec.strength * rec.salience) / 100;
      if (w > summary.domain_strength[rec.domain]) {
        summary.domain_strength[rec.domain] = w;
      }
    }

    // Track newest touch
    if (rec.domain == DOMAIN_TOUCH && rec.formed_at_ms > newest_touch_ms) {
      newest_touch_ms = rec.formed_at_ms;
    }

    // Count by category
    if (rec.category == MEM_CAT_EPISODIC) summary.episodic_count++;
    if (rec.category == MEM_CAT_FAMILIARITY) summary.familiarity_count++;
    if (rec.category == MEM_CAT_SIGNIFICANT) summary.significant_present = 1;
  }

  summary.ms_since_last_touch = (newest_touch_ms > 0)
    ? (now - newest_touch_ms)
    : 0xFFFF;  // sentinel: no touch memory
  summary.total_records = record_count_;

  return summary;
}
```

## Behavior Modulation (Sprint 1)

Two modulation rules active in `FaceEngineClass::updateAnimations()`:

### Rule 1: Recent Touch → Slow Decay
- **When:** `ms_since_last_touch < 30 minutes (1800000 ms)`
- **Effect:** `decay *= 0.80f` (engagement_drive decays 20% slower)
- **Rationale:** Recent interaction signals the creature is engaged — delay the withdrawal
- **Bound:** Always apply, no minimum engagement check

### Rule 2: Prolonged Absence → Raised Engagement Floor
- **When:** `ms_since_last_touch > 30 minutes (1800000 ms)` AND `domain_strength[DOMAIN_TOUCH] < 10`
- **Effect:** `floor_val = max(floor_val, 5.0f)` (raises minimum engagement from 0 to 5)
- **Rationale:** Creatures that remember touch want to seek it again — maintain baseline attention
- **Bound:** Must stay within original float range; floor is always ≤ current max engagement

## Exit Criteria

- [ ] `MemoryEngine.begin()` prints `[MEM] begin -> 0 records` on boot
- [ ] Single tap forms TOUCH_TAP record (serial: `[MEM] formed TOUCH TAP salience=20`)
- [ ] Double tap forms TOUCH_DOUBLE (serial confirms `salience=35`)
- [ ] Hold (>2s) forms TOUCH_HOLD (`salience=40`)
- [ ] Burst (5 taps in 10s) forms TOUCH_BURST (`salience=55`)
- [ ] Duplicate events within 60s boost existing record (+10 salience) instead of creating new
- [ ] `recall()` returns `ms_since_last_touch < 1800000` during touch window
- [ ] `recall()` returns `domain_strength[DOMAIN_TOUCH]` proportional to strongest recent touch
- [ ] After 60-min without touch, `ms_since_last_touch > 1800000` and `domain_strength[DOMAIN_TOUCH] < 10`
- [ ] engagement_drive decay visibly slows by 20% during active touch window (serial log confirms)
- [ ] After prolonged absence, engagement floor rises to 5 (serial log confirms `floor=5.0`)
- [ ] After 30-min run: no crashes, heap within 2KB of starting value
- [ ] `[MEM] records=256` when full — eviction works correctly, no crash
- [ ] All modulations stay within V2.5 min/max bounds (verified by assertion or log)
