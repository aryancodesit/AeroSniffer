## Objective

Build a physical-model and biological animation layer (Animation Intelligence Layer) within FaceEngine that governs lifelike eye movement, breathing, focus locking, emotional recovery, and transition polish — with zero changes to behavioral engines or CreatureState.

## Scope

| Feature | Description |
|---------|-------------|
| **Physical Saccades** | Spring-damper eye movement (Target → Velocity → Ease → Settle) with micro-drift tremor |
| **Biological Breathing** | 4-phase non-symmetrical breathing cycle (inhale → hold → exhale → rest) modulating eye scale and position |
| **Focus Lock** | Hysteresis-based suspension of random saccades, locking gaze to attention source |
| **Emotional Recovery** | Slow 1.5–2s decay of brows and eyelids when reverting from ALERT/ANGRY to CALM |
| **Transition Polish** | 4-phase state machine (IDLE → Anticipate → Transition → Settle) with squeeze and overshoot |
| **PresentationTarget** | Additive Stage 1 output contract — no changes to Sprint 1 PresentationState |
| **Integer-Only Stage 3** | All float→int resolution in Stage 2; rasterization receives only integer coordinates |
| **ANIM_DEBUG Overlay** | Build-time display overlay showing current emotion + touch state |
