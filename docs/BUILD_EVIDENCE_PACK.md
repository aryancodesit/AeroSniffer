# Build Evidence Pack

Generated by `python3 tools/releng.py evidence` from existing `build/` artifacts.
Consumed by specialist agents (`/link`, `/ci`, `/esp32`, `/display`, `/cpp`, `/release`)
for offline diagnosis — no CI re-push needed.

## Location

| Context | Path |
|---|---|
| Local build | `build/evidence/` |
| CI run | `build-evidence-<sha>.zip` (downloadable artifact) |
| Unpacked | `{workspaceFolder}/build/evidence/` (after manual unpack) |

## Directory Structure

```
build/evidence/
├── manifest.yaml          # Metadata: generation time, exit code, artifact presence flags
├── build.log              # Full stdout from arduino-cli compile (captured via tee)
├── build.err              # Stderr from compile (if separated)
│
├── deps/
│   ├── core_list.txt          # arduino-cli core list
│   ├── lib_list.txt           # arduino-cli lib list
│   ├── boards.txt.extract     # XIAO_ESP32S3 section only
│   ├── pins_arduino.h         # Variant pin definitions
│   ├── partitions.csv         # Partition table (e.g. partitions-8MB.csv)
│   ├── User_Setup.h           # Deployed TFT_eSPI configuration
│   ├── platform.txt.extract   # XIAO_ESP32S3 section of platform.txt
│   └── compiler_version.txt   # xtensa-esp32s3-elf-g++ --version output
│
├── flags/
│   ├── all_defines.txt          # All -D flags extracted from build log (sorted, unique)
│   ├── AeroSniffer.ino.cpp.flags  # Full compile command for sketch
│   ├── TFT_eSPI.cpp.flags         # Full compile command for TFT_eSPI
│   ├── HWCDC.cpp.flags            # Full compile command for HWCDC
│   └── platform/                  # Per-unit flag files from arduino15 packages
│
├── preprocessed/
│   └── AeroSniffer.ino.cpp    # Preprocessor output (macros expanded)
│
├── symbols/
│   ├── core.a.symbols         # nm -C output for core.a (all symbols)
│   ├── sketch.symbols         # nm -C per-object-file for sketch
│   └── unresolved.txt         # Filtered list of unresolved (U) symbols in core.a
│
├── maps/
│   ├── firmware.map           # Full linker map (AeroSniffer.ino.map)
│   ├── sections.txt           # xtensa-esp32s3-elf-size -A output
│   └── largest_symbols.txt    # nm --size-sort -C tail -50 (largest by size)
│
├── sdkconfig/
│   └── sdkconfig.h            # IDF SDK configuration (first found in arduino15)
│
└── git/
    ├── describe.txt            # git describe --tags --dirty
    ├── diff.txt                # git diff (working tree changes)
    └── status.txt              # git status --porcelain
```

## How Agents Use the Pack

1. **Check manifest.yaml** for artifact availability before attempting analysis
2. **Load build.log** for error messages, compile commands, link commands
3. **Load flags/all_defines.txt** for -D guard verification
4. **Load symbols/core.a.symbols** for symbol existence checks
5. **Load maps/firmware.map** for section layout and symbol addresses
6. **Load deps/*.txt** for version mismatch detection
7. **Cross-reference** across artifacts to determine root cause

## Generating the Pack

```bash
# After a local build
python3 tools/releng.py build --no-install 2>&1 | tee build/build.log
python3 tools/releng.py evidence
```

In CI, the workflow runs these steps automatically and uploads
`build/evidence/` as `build-evidence-<sha>.zip`.

## Updating the Schema

Add new artifacts to `cmd_evidence()` in `tools/releng.py`.
Each artifact should:
- Have a clear purpose (linked to a real failure scenario)
- Be small (<1 MB unless essential)
- Be referenced in the manifest for agent detection
