# V2.8 Sprint 2 — Animation Intelligence Specification
## Objective
Implement a presentation-only **Animation Intelligence Layer** in `FaceEngine` that translates raw presentation profiles into organic, lifelike biological behaviors (breathing, physical eye movement, recovery periods, transition phases) with zero changes to behavioral engines.

## 1. Physical Eye Saccades (Target → Velocity → Ease → Settle)
Instead of immediate coordinate snapping during random wander (saccades), eye movement follows a physical model with mass, spring tension, and friction damping.

### Physics Model (Spring-Damper)
For coordinates $x$ and $y$:
$$\text{accel}_x = (x_{\text{target}} - x_{\text{current}}) \cdot K_{\text{tension}} - v_x \cdot K_{\text{damping}}$$
$$v_x \leftarrow v_x + \text{accel}_x \cdot dt$$
$$x_{\text{current}} \leftarrow x_{\text{current}} + v_x \cdot dt$$

Where:
- $K_{\text{tension}} \approx 0.15$ (elastic pull toward target)
- $K_{\text{damping}} \approx 0.40$ (friction preventing perpetual oscillation)
- $dt \approx 1.0$ (frame step)

### Saccade Settle & Micro-Drift
- **Settling:** When the eyes arrive near the target ($|x_{\text{target}} - x_{\text{current}}| < 0.2$), velocity is damp-killed to prevent micro-jitter.
- **Micro-Drift (Tremor):** In steady state, a continuous, organic tremor is added to simulate physiological eye drift (amplitude $\pm0.3$ pixels, frequency ~12Hz).

## 2. Biological Breathing Cycles
Breathing replaces the simple sine bounce. It is non-symmetrical, mimicking actual physiology: inhale, brief hold, slower exhale, rest.

```
  1.0 ┼      ┌───────┐
      │     /         \
      │    /           \
  0.0 ┼───┘             └───
      └───In───Hold───Ex───Rest──
```

### Waveform Generator
A phase accumulator `breath_phase` ($0 \dots 2\pi$) drives a non-linear shape:
- **Inhale ($0 \dots 0.35\pi$):** Fast expansion.
- **Hold ($0.35\pi \dots 0.45\pi$):** Slight pause at full lung capacity.
- **Exhale ($0.45\pi \dots 0.8\pi$):** Linear/exponential contraction.
- **Rest ($0.8\pi \dots 2\pi$):** Flat baseline at resting state.

### Modulators
Breathing modulates:
- **Eye scale:** Vertical scale fluctuates by $+2\%$ during inhale, $-1\%$ during exhale.
- **Vertical position:** Saccades drift up by $+0.5$ pixels during inhale.

## 3. Focus Lock
Attention strength governs the dampening of random wander.

- **Attention Locked (`g_creature.attention.strength >= 25`):**
  - Target coordinate is fixed to the attention source (e.g., skyward for flights, centered-up for user).
  - Random saccade timer is suspended.
  - Saccade amplitude is strictly bounded to micro-drift and subtle breathing.
- **Attention Soft (`g_creature.attention.strength < 25`):**
  - Resumes slow, wide-range random wander (glances, inspection arcs).

---

## 4. Emotional Recovery Curve (Anticipation → Decay)
When transitioning from high-energy negative states (`ALERT`, `ANGRY`) to `CALM`, a temporary biological decay modifier prevents immediate visual snapping.

- **Recovery State:** Stores `recovery_modifier` ($1.0 \dots 0.0$).
- **Trigger:** Shifting out of high-intensity states.
- **Effect:**
  - Furrowed brow angle decays linearly over 1.5 seconds.
  - Eyelid openness returns slowly over 2 seconds.

---

## 5. Transition Polish (IDLE → Anticipation → Settle)
Emotion transitions are split into four physical phases to convey weight:

```
  Phase       Duration   Visual Effect
  ─────────────────────────────────────────────────────────────
  IDLE        Steady     No transition active; settled state
  Anticipate  ~50ms      Eyes squeeze slightly (compress by 10% y)
  Transition  ~150ms     Shape snaps, color lerps, size expands
  Settle      ~100ms     Overshoot final size by 5% and elastic bounce
```

The `TransitionPhase` enum is defined in `V2.8_RENDER_PIPELINE.md` and mirrors this table.
Phase advances are driven by wall-clock elapsed time (`_transition_timer_ms`), not frame count.

## 6. Architecture Rules

### Stage 3 (Rasterization) — Integer AnimationPose Only
`drawEye()` and `drawBrows()` receive integer coordinates exclusively. All float → int resolution happens in Stage 2 (Animation Intelligence) when producing the `AnimationPose` cache. Stage 3 never performs sub-pixel arithmetic.

### Wall-Clock dt for Spring Physics
The spring-damper integrator uses the actual elapsed wall-clock time (`micros()`) normalized to a 60fps frame (16.66ms). dt values >3.0 are clamped to prevent physics explosion on frame skips. The animation system is decoupled from the frame counter.

### Focus-Lock Hysteresis
Focus lock engages at `attention.strength >= 25` and releases at `strength < 20`. The 5-point hysteresis band prevents rapid lock/unlock oscillation when attention strength fluctuates near the threshold.

### PresentationTarget (Additive)
`updatePresentation()` emits a `PresentationTarget` struct alongside the existing `PresentationState`. Stage 2 (`updateAnimations()`) reads `PresentationTarget` as its input contract. Stage 1's internal `PresentationState` is preserved unchanged.

### TransitionPhase & transition_progress
`TransitionPhase` (IDLE/ANTICIPATE/TRANSITION/SETTLE) governs physical animation effects (squeeze, overshoot) alongside the existing `transition_progress` (0-255), which governs Sprint 1 profile blending. Both are driven by the same transition event; TransitionPhase advances via wall-clock timer while `transition_progress` advances incrementally.

### Animation Execution Order
```
Animation Execution Order (within updateAnimations):
1. Compute wall-clock dt from micros()
2. Update eyelid factor (engagement-based drowsiness)
3. Update mood presentation (if mood/strength changed)
4. Update blink state
5. Update TransitionPhase state machine (advance timer, phase transitions)
6. Compute biological breathing waveform
7. Update emotional recovery curve
8. Compute attention-driven gaze target (with focus-lock hysteresis)
9. Integrate spring-damper physics (EyePhysics: target→velocity→position)
10. Apply micro-drift to EyePhysics
11. Resolve bounce from mood + breathing
12. Resolve pulse animation
13. Produce AnimationPose (integer) from physics state + PresentationTarget
14. Maintain backward-compat fields (anim_look_x/y, anim_bounce_y)
```

### Minimum Target Hold (Desktop Observer)
The attention-driven gaze target (`_eye_physics.target_x/y`) is held for a minimum of 1000ms before a new random saccade is generated. This prevents rapid micro-saccades during idle wander and ensures the creature appears to "look at" a point before glancing elsewhere. The hold duration is modulated by engagement_drive (3s at 100% engagement, up to 30s at 0%). The Desktop Observer mode (future) may override this hold to follow screen content.
