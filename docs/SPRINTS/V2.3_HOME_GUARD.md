# V2.3-B Home Guard Foundation

## Objective

Build presence intelligence on top of existing device discovery.

## Scope

- Trusted devices
- Familiar devices
- Presence state
- First seen
- Last seen
- Portal visibility

## Success Criteria

- Devices persist between scans
- Trusted devices can be identified
- Presence state visible in portal
- Trusted return events generated

## Non Goals

- Cloud sync
- Push notifications
- User accounts
- Device fingerprinting
