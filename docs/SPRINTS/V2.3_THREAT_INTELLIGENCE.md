# V2.3 Threat Intelligence

## Objective

Convert telemetry into actionable security events.

## Scope

- Unknown device detection
- Randomized MAC detection
- Trusted device return detection
- Threat event classification
- Portal threat visualization

## Non Goals

- Machine learning
- Cloud analytics
- Device fingerprinting
- Vendor lookup APIs

## Success Criteria

- Threats visible in portal
- Events stored in ring buffer
- No measurable stability regression
