# V2.4 Stability Report — Mode Transition Milestone

**Date**: 2026-06-19
**Tag**: `v2.4-transition-stable`
**Branch**: `feature/v2.4-companion-intelligence`
**Hardware**: DeskBuddy 2.0 — XIAO ESP32S3 + ST7789 240x240

---

## 1. Fixed Issues Confirmed by Runtime

### 1.1 Pet → Security Transition
- **Status**: ✅ Clean (with weather fetch disabled)
- **Evidence**: 10+ transitions completed; all breadcrumbs fire; no WDT, no assertion, no hang
- **Fix**: Removed `portENTER_CRITICAL` spinlock from `AttentionEngine.pause()` (B005)

### 1.2 Security → Aviation Transition
- **Status**: ✅ Clean (with weather fetch disabled)
- **Evidence**: Transitions complete; `netstack cb reg failed with 12308` appears but is non-fatal
- **Note**: Root cause of netstack error still unknown but does not block operation

### 1.3 Aviation → Pet Transition
- **Status**: ✅ Clean (with weather fetch disabled)
- **Evidence**: Full cycle 2→0 completes without crash

### 1.4 OpenSky HTTP Fetch
- **Status**: ❌ Fails — `connection refused` (HTTP Code -1)
- **Root cause**: Unknown — DNS, TLS, or routing issue. `WiFi.status() == WL_CONNECTED` at time of fetch.
- **Next step**: Test HTTP (non-TLS) to isolate; verify certificate bundle

### 1.5 JSON Parse
- **Status**: ✅ No JSON-related crashes observed
- **Evidence**: All JSON parsing in log output and preferences loading succeeds

### 1.6 WiFi Connect/Disconnect Lifecycle
- **Status**: ✅ Clean on mode entry/exit
- **Evidence**: `[WiFiService] Stop WiFi` with correct owner/mode/promisc; `[WiFiService] WiFi stopped.` confirms clean teardown. `connectSTA()` with PMF fix succeeds on re-entry.

### 1.7 Touch Responsiveness After WiFi
- **Status**: ✅ Working (with caveat)
- **Evidence**: Touch events register correctly in all modes after WiFi operations
- **Caveat**: `g_block_touch` flag can suppress touch during certain transitions; not a stability blocker

## 3. Suggested Regression Tests

Run these after any firmware change:

### Mode Transition (5 cycles minimum)
```
Long press in Pet  → verify Security boots, touch works
Long press in Sec  → verify Aviation boots, touch works
Long press in Av   → verify Pet boots, touch works
Cycle 5 times, check for WDT, assertion, or hang
```

### Touch Responsiveness
```
Tap 10 times in each mode → verify emotion transitions fire
Long press in each mode   → verify mode switch triggers
Verify no phantom touches or missed events
```

### WiFi Lifecycle
```
Mode switch Pet→Security: verify WiFi stopped log
Mode switch Security→Aviation: verify WiFi stopped + STA connect logs
Mode switch Aviation→Pet: verify WiFi stopped log
```

### Serial Breadcrumbs (crash isolation)
```
Verify all breadcrumbs appear in correct order during transition:
  BEFORE teardown → AFTER teardown → [ATTN] pause → AFTER pause
  → AFTER splash → BEFORE setup → AFTER setup
  → [ATTN] resume → AFTER resume
```

### Memory Stability
```
Monitor for heap fragmentation over 30 min of mode cycling
Monitor for Serial buffer overrun (truncated log lines)
```
