# V2.6 Memory Layer — Taxonomy

## Memory Categories (3 types)

```
MEM_CAT_EPISODIC     (1) — "A deauth burst happened 3 hours ago"
MEM_CAT_FAMILIARITY  (2) — "Security events have been frequent today"
MEM_CAT_SIGNIFICANT  (3) — "An evil twin attack happened" (salience >= 70)
```

All three types share the same `MemoryRecord` struct. They differ in:
- **Episodic**: formed on event, decays over hours, max 256 total
- **Familiarity**: formed when sliding-window frequency crosses threshold, decays faster (4h half-life)
- **Significant**: auto-promoted from episodic when `salience >= 70`, immune to routine pruning

## Domains (5)

### 1. DOMAIN_TOUCH (0)

| Subtype | Value | Condition | Base Salience | Notes |
|---------|-------|-----------|---------------|-------|
| TOUCH_TAP | 0x01 | Single short press (debounced) | 20 | Most common touch event |
| TOUCH_DOUBLE | 0x02 | Two taps within 500ms | 35 | Curiosity/play signal |
| TOUCH_HOLD | 0x03 | Press > 2 seconds | 40 | Comfort-seeking behavior |
| TOUCH_BURST | 0x04 | >= 5 taps in 10s window | 55 | Excitement / frustration |
| TOUCH_LONG_HOLD | 0x05 | Press > 10 seconds | 60 | Deep connection / distress |

**Data payload (16 bytes):**
```cpp
struct {
  uint16_t touch_duration_ms;
  uint8_t  tap_count_window;     // taps in last 60s
  uint8_t  _pad[13];
} touch;
```

## Context Multiplier Table

Context multiplier is applied to base salience at formation time. Applied multiplicatively: `final_salience = clamp(base × ctx_mul, 0, 100)`.

| Context Condition | Multiplier | Applies To |
|------------------|------------|------------|
| Nighttime (20:00-06:00, approximated via uptime > 12h) | 1.3 | All domains |
| Creature is in an anxious mood | 1.2 | SECURITY, ATTENTION |
| Creature is in a playful mood | 0.8 | SECURITY (less threat sensitivity) |
| Same subtype formed < 60s ago | 0.6 | All (novelty decay) |
| Opposite subtype in same domain < 120s ago | 1.4 | All (contrast boost) |
| `mood_strength > 70` | 1.2 | MOOD, ATTENTION |
| `mood_strength < 20` | 0.7 | MOOD (numbed) |
| Current mode is Companion | 1.2 | TOUCH |
| Current mode is Security | 1.3 | SECURITY |
| Current mode is Aviation | 1.2 | AVIATION |

## Salience → Significance Mapping

```
0-20   →  ephemeral     (pruned aggressively after 1h)
21-40  →  normal        (pruned after half-life expires)
41-60  →  durable       (survives 2 full half-life cycles)
61-80  →  important     (survives 3 full half-life cycles, auto-promote at >=70 to SIGNIFICANT)
81-100 →  core          (survives 4 cycles, immune to routine pruning when labeled SIGNIFICANT)
```

Episodic records with `salience >= 70` are auto-promoted to `MEM_CAT_SIGNIFICANT` at formation time. Significant records are excluded from the routine pruning pass — they decay to strength 0 before being removed.
