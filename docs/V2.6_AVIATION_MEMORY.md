# V2.6 Sprint 3 — Aviation Memory Domain

**Status:** Sprint 3 Design Review — REVISED
**Domain:** DOMAIN_AVIATION (2)
**Value:** 2

---

## Purpose

The creature remembers meaningful aviation observations. This aligns with the Aviation Observer product identity.

What memory should answer:
- What has the device observed recently?
- Was the sky active or quiet?

What memory should NOT answer:
- What is the current traffic density? (AviationObserver's job)
- Should I look at the sky? (AttentionEngine decides that)

---

## Subtypes

| Subtype | Value | Condition | Base Salience |
|---------|-------|-----------|---------------|
| AVI_AIRCRAFT_SPOTTED | 0x20 | Standard aircraft detected via OpenSky | 22 |
| AVI_QUIET_SKY_PERIOD | 0x21 | No aircraft seen for >= 30 min | 16 |
| AVI_UNUSUAL_TRAFFIC_EVENT | 0x22 | Rare flight (`is_rare==true`) or extreme altitude (< 1000 ft or > 45000 ft) | 42 |

**AVI_HIGH_TRAFFIC_WINDOW deferred to Sprint 4.** A hardcoded threshold (e.g., 8 flights in 10 min) would be wrong in airport vs rural areas. Sprint 4 adds baseline accumulation for relative traffic comparison.

## Data Payload

```cpp
struct {
  uint32_t icao24;          // ICAO 24-bit aircraft identifier (0 if N/A for quiet sky)
  int16_t  altitude_ft;     // -1 = unknown, valid range 0-60000
  uint8_t  is_rare;         // 0/1
  uint8_t  _pad[9];
} aviation;
```

Total: 4 + 2 + 1 + 9 = 16 bytes.

**ICAO correction:** ICAO identifiers are 24-bit. Stored in `uint32_t`. `uint16_t` from the original spec would cause collisions (many aircraft share low 16 bits). The `source_id` field at the MemoryRecord level stores the full ICAO24 — this payload field is for quick payload scanning and dedup.

## Formation Rules

### Event-Driven Formation

```
EVENT_FLIGHT_DETECTED
  → if altitude < 1000 ft or altitude > 45000 ft → AVI_UNUSUAL_TRAFFIC_EVENT
  → else → AVI_AIRCRAFT_SPOTTED

EVENT_FLIGHT_RARE
  → AVI_UNUSUAL_TRAFFIC_EVENT (immediate, overrides altitude check)
```

### Time-Based Formation

```
observe() every tick:
  → if no flight event received for >= 30 min:
      AND last_quiet_sky_at_ms + 3600000 < now (max 1 per hour):
        → AVI_QUIET_SKY_PERIOD
```

Quiet sky is the only non-event-driven aviation subtype. Formed by absence of events.

### Tracking State

```cpp
// In MemoryEngine:
uint32_t avi_last_flight_ms_;
uint32_t avi_last_quiet_sky_ms_;
```

On `EVENT_FLIGHT_DETECTED`:
```
avi_last_flight_ms_ = millis()

if (altitude_ft >= 0) and (altitude_ft < 1000 or altitude_ft > 45000):
  observe_aviation(AVI_UNUSUAL_TRAFFIC_EVENT, icao24, alt, rare=1)
else:
  observe_aviation(AVI_AIRCRAFT_SPOTTED, icao24, alt, rare=0)
```

On `EVENT_FLIGHT_RARE`:
```
observe_aviation(AVI_UNUSUAL_TRAFFIC_EVENT, icao24, alt, rare=1)
avi_last_flight_ms_ = millis()
```

## Integration Point

```cpp
static void memory_event_callback(EventType event, void* data) {
  switch (event) {
    case EVENT_TOUCH_SHORT:
      // ... existing
      break;
    case EVENT_ATTACK_DEAUTH:
    case EVENT_ATTACK_EVILTWIN:
    case EVENT_DEVICE_TRUSTED:
    case EVENT_DEVICE_FAMILIAR:
    case EVENT_DEVICE_UNKNOWN:
    case EVENT_NETWORK_DISCOVERED:
      MemoryEngine.onSecurityEvent(event);
      break;
    case EVENT_FLIGHT_DETECTED:
    case EVENT_FLIGHT_RARE:
      MemoryEngine.onFlightEvent(event, data);
      break;
    default:
      break;
  }
}
```

## Salience

| Subtype | Base | Effective Range | Comparison |
|---------|------|-----------------|------------|
| AVI_AIRCRAFT_SPOTTED | 22 | 22-29 (Aviation mode: 1.2x) | Same as TAP |
| AVI_QUIET_SKY_PERIOD | 16 | 16-21 | Below TAP — passive observation |
| AVI_UNUSUAL_TRAFFIC_EVENT | 42 | 42-50 (Aviation mode: 1.2x, Night: 1.3x) | Above BURST (45) under night multiplier |

---

## Dedup Window

**180 seconds (3 min)** for AVI_AIRCRAFT_SPOTTED and AVI_UNUSUAL_TRAFFIC_EVENT.

Rationale: OpenSky scans every ~30-60s. Same aircraft appears in consecutive scans. 3-min window prevents duplicates while allowing distinct aircraft to form separate records.

**AVI_QUIET_SKY_PERIOD cooldown: 3600s (1 hour).** Forming more than once per hour is noise.

---

## Decay

**Half-life: 4 hours.** Aviation memories fade fastest. A flight from 8 hours ago is nearly forgotten. Yesterday's sky state is irrelevant today.

---

## Anti-Flood Safeguards

1. **Dedup window (3 min)** prevents same-aircraft duplicates (checked against source_id / ICAO24).
2. **Quiet sky cooldown (1 hour)** prevents redundant records.
3. **Only first detection per flight matters** — Mode3_Aviation.h already fires `EVENT_FLIGHT_DETECTED` once per aircraft per scan cycle.
