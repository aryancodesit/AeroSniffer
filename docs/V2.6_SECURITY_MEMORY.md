# V2.6 Sprint 3 — Security Memory Domain

**Status:** Sprint 3 Design Review — FINAL
**Domain:** DOMAIN_SECURITY (1)
**Value:** 1

---

## Purpose

The creature remembers meaningful security experiences. Security subtypes represent *experiences*, not raw implementation events.

**Principle:** If it is not meaningful, no memory forms. A single deauth in isolation is not a memory. A trusted device reconnecting is a device appearance. A deauth burst is suspicious. An evil twin is a threat.

What memory should answer:
- What security experiences happened recently?
- How important were they?
- How often did they occur?

What memory should NOT answer:
- What is the current threat level? (SecurityEngine's job)
- Should I change behavior? (Behavior Layer V2, deferred)

---

## Subtypes

| Subtype | Value | Meaning | Base Salience |
|---------|-------|---------|---------------|
| SEC_DEVICE_APPEARED | 0x10 | A device appeared on the network — new, returning, or switching connectivity | 25 |
| SEC_SUSPICIOUS_ACTIVITY | 0x11 | Unusual pattern detected (multiple deauths, probe scans, elevated rate) | 38 |
| SEC_THREAT_DETECTED | 0x12 | Active attack confirmed (evil twin, deauth burst >= 5 in 60s) | 50 |

Three subtypes. No OBSERVATION — routine ambient events do not form memory.

---

## Data Payload

```cpp
struct {
  uint8_t  threat_level;     // 0-100, from SecurityEngine assessment
  uint8_t  event_count;      // count since last dedup reset
  uint8_t  _pad[14];
} security;
```

No `source_id_hash`. `MemoryRecord.source_id` is the single source of truth for device identity.

Total: 16 bytes (matches union size).

## Formation Rules

### Deauth Window Tracking

```
EVENT_ATTACK_DEAUTH
  → if burst count >= 5 in 60s → THREAT_DETECTED
  → if count 2-4 in 60s       → SUSPICIOUS_ACTIVITY
  → single, in isolation       → no memory (routine activity)

EVENT_ATTACK_EVILTWIN
  → THREAT_DETECTED (always a confirmed threat)
```

```cpp
// In MemoryEngine:
uint32_t sec_deauth_window_start_;
uint8_t  sec_deauth_count_;
bool     sec_suspicious_formed_;

On EVENT_ATTACK_DEAUTH:
  if (millis() - sec_deauth_window_start_ > 60000):
    reset window

  sec_deauth_count_++

  if sec_deauth_count_ >= 5:
    observe_security(SEC_THREAT_DETECTED, sec_deauth_count_, level)
    reset window
  else if sec_deauth_count_ >= 2 && !sec_suspicious_formed_:
    observe_security(SEC_SUSPICIOUS_ACTIVITY, sec_deauth_count_, level)
    sec_suspicious_formed_ = true
  // count == 1: no memory forms
```

### Device Events

```
EVENT_DEVICE_TRUSTED/FAMILIAR  → observe_security(SEC_DEVICE_APPEARED, 1, level)
EVENT_DEVICE_UNKNOWN           → observe_security(SEC_DEVICE_APPEARED, 1, level)
```

`EVENT_NETWORK_DISCOVERED` → no memory (routine scan cycle).

### Integration Point

```cpp
static void memory_event_callback(EventType event, void* data) {
  switch (event) {
    case EVENT_TOUCH_SHORT: {
      TouchEventData* td = (TouchEventData*)data;
      MemoryEngine.onTouchEvent(td ? td->duration_ms : 0);
      break;
    }
    case EVENT_ATTACK_DEAUTH:
    case EVENT_ATTACK_EVILTWIN:
    case EVENT_DEVICE_TRUSTED:
    case EVENT_DEVICE_FAMILIAR:
    case EVENT_DEVICE_UNKNOWN:
      MemoryEngine.onSecurityEvent(event);
      break;
    default:
      break;
  }
}
```

`EVENT_NETWORK_DISCOVERED` is intentionally excluded — ambient scan results do not form memory.

## Salience

| SEC_DEVICE_APPEARED | 25 | Security mode: 1.3x | 25-33 |
| SEC_SUSPICIOUS_ACTIVITY | 38 | Anxious: 1.2x, Security mode: 1.3x | 30-49 |
| SEC_THREAT_DETECTED | 50 | Anxious: 1.2x, Security mode: 1.3x, Night: 1.3x | 50-65 |

---

## Dedup Window

**300 seconds (5 min)** for all security subtypes. A burst is one incident, not 30 separate memories.

**Exception:** SEC_THREAT_DETECTED from `EVENT_ATTACK_EVILTWIN` always forms a new record.

---

## Decay

**Half-life: 12 hours.**

---

## Anti-Flood Safeguards

1. **Dedup window (5 min)** prevents repeat redundancy.
2. **Deauth burst window (60s sliding):** one formation per window at highest severity.
3. **No OBSERVATION subtype:** routine events produce zero records.
4. **No per-packet memory:** only processed events that pass SecurityEngine thresholds.

---

## What Does NOT Change

- SecurityEngine, Sniffer, HomeGuard, EvilTwin — no changes.
- EventBus — no changes.
- `EventType` enum — no changes.
- Touch pipeline — untouched.
